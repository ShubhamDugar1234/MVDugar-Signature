How to install it
  1. Gmail — Copy signature, then Settings → See all settings → General → Signature → paste. Do not retype anything afterwards; it strips the formatting.
  2. Outlook (web) — Settings → Mail → Compose and reply → paste into the signature box.
  3. Outlook (desktop) — use Download for Outlook, then File → Options → Mail → Signatures → New, and paste the contents of the downloaded file.
  4. Apple Mail — paste, then untick Always match my default message font.
For whoever rolls this out
  1. Pre-fill for someone else. Fill in their details, press Copy pre-filled link, send it to them. They open it and press Copy — nothing to explain.
  2. Changing divisions, brands, wording or spacing. Don't edit this file by hand — use the admin page. It edits everything and exports a fresh copy of this page.
  3. Switch to hosted logos. Logos are embedded here, which makes each signature heavier and can show as an attachment in old Outlook. Once the PNGs are on the website, set hostedBase in the admin page to e.g. https://mvdugar.com/sig/ and every logo switches to a URL. Filenames must match the keys — mvdugar.png, johndeere.png.
